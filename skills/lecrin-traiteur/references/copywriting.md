# Copywriting — L'Écrin Traiteur

## Ton de voix

**En 3 mots :** Ancré, chaleureux, précis.

L'Écrin s'adresse à des professionnels qui veulent bien traiter leurs équipes sans y passer une heure. Le ton doit être :
- **Chaleureux** sans être familier — on ne dit pas "Bonjour les amis !"
- **Précis** sans être technique — on nomme les producteurs, pas les labels
- **Confiant** sans être arrogant — on montre, on ne se vante pas
- **Direct** sans être froid — on dit ce qu'on fait, sans circumlocutions

Écrire comme si un ami bien informé expliquait pourquoi cette viennoiserie est extraordinaire — pas comme une brochure commerciale, pas comme un menu de brasserie générique.

## Vocabulaire à utiliser

### Pour parler des produits
```
✅ sourcé, identifié, de saison, du terroir
✅ boulangerie artisanale, fromager affineur, producteur local
✅ fabriqué à la main, au levain naturel, sans conservateur
✅ viennoiserie, brioché, feuilletage, ganache, compote maison
✅ origine : [nom du producteur], [région/département]
```

### Pour parler du service
```
✅ livraison soignée, présentée avec soin
✅ adaptée à vos équipes, à votre rythme
✅ devis sur mesure, proposition personnalisée
✅ zone de livraison : Paris et Île-de-France
✅ commande flexible, délai [X jours] à l'avance
```

### Pour l'identité de marque
```
✅ L'Écrin (pas "L'écrin" ni "l'Écrin")
✅ "Traiteur artisanal" ou "L'Écrin Traiteur" dans les contextes formels
✅ "l'écrin" (minuscule) dans les métaphores : "comme un écrin, chaque plateau..."
```

## Vocabulaire à éviter

### Généralités sans substance
```
❌ "de qualité", "de qualité supérieure", "haute qualité"
❌ "produits frais" (vague — tout le monde le dit)
❌ "produits premium" (anglicisme marketing vide)
❌ "saveurs authentiques"
❌ "le meilleur traiteur de Paris"
❌ "une équipe de passionnés"
❌ "à l'écoute de vos besoins"
❌ "solutions sur mesure pour votre entreprise"
```

### Formules commerciales usées
```
❌ "N'hésitez pas à nous contacter"
❌ "Nous sommes à votre disposition"
❌ "Pour toute demande, contactez-nous"
❌ "Notre expertise, votre satisfaction"
❌ "Faites confiance à L'Écrin"
❌ "Profitez de nos offres"
```

### Superlatifs non prouvés
```
❌ "inégalé", "incomparable", "unique en son genre"
❌ "le seul traiteur à..."
❌ "exceptionnellement bon"
```

## Formules d'accroche — exemples concrets

### Pour la page d'accueil
```
✅ "Le terroir, livré dans vos bureaux."
✅ "Chaque plateau, sourcé. Chaque livraison, soignée."
✅ "Des petits déjeuners qui commencent bien la journée — vraiment."
✅ "Vos équipes méritent mieux qu'une boîte de madeleines industrielles."
```

### Pour les offres
```
✅ "Notre petit déjeuner commence chez le boulanger, pas dans un entrepôt."
✅ "Un goûter qui fait parler — pour les bonnes raisons."
✅ "Plateau repas : ce que vous mettez sur la table dit quelque chose de vous."
```

### Pour l'à propos
```
✅ "L'Écrin est né d'une conviction simple : un plateau livré peut être beau."
✅ "On a commencé à chercher les meilleurs producteurs avant de chercher des clients."
```

## Règles de style

### Ponctuation et typographie
- Guillemets français : « » (pas "")
- Tirets longs dans les listes : — (pas -)
- Espaces insécables avant : !, ?, ;, :
- Majuscule à L'Écrin toujours (même en milieu de phrase)

### Longueur des textes
```
Titre H1 hero        : 3-7 mots. Court. Fort. Pas une phrase complète.
Sous-titre hero      : 1 phrase, max 120 caractères
Intro de section     : 2-3 phrases. Pas plus.
Description d'offre  : 3-5 lignes. Contexte + produits clés + origine.
Détails d'offre      : 3-4 items en liste courte. Chaque item = 1 ligne.
Texte À Propos       : paragraphes de 3-5 lignes. Aéré. Pas de blocs denses.
```

### Structure des descriptions d'offre
```
1. Ligne de contexte : à quel moment, pour quelle occasion
   ex : "Pour démarrer la journée avec les équipes, ou accueillir un client."

2. Contenu typique : 3-4 produits nommés avec précision
   ex : "Croissants au beurre AOP, pain au levain maison, jus d'orange pressé, 
         confitures en petits pots de la Maison Beillevaire."

3. Origine (obligatoire) : au moins 1 producteur nommé
   ex : "Viennoiseries : Boulangerie Legrand, Paris 11e."

4. Détail pratique : minimum de personnes, délai, format de livraison
   ex : "À partir de 10 personnes. Commande 48h à l'avance."
```

## Ton par page

### Accueil
Ton : séduisant et direct. On doit avoir envie de continuer. Chaque section a un seul message.

### Offres
Ton : précis et appétissant. On nomme, on décrit le concret. Pas de métaphores abstraites.

### Notre Histoire
Ton : narratif et humain. On raconte comme on parlerait. Pas de communiqué de presse.

### Contact
Ton : rassurant et efficace. On retire les frictions. Pas de jargon juridique.

## Messages de confirmation (formulaire)

Le message après envoi du devis doit être humain et spécifique — pas un message système.

```
✅ "Merci [Prénom], votre demande est bien reçue.
     Nous revenons vers vous sous 24h avec une proposition
     personnalisée pour vos [type de repas]."

✅ "Votre demande est entre de bonnes mains.
     [Prénom de contact] de l'équipe L'Écrin vous contacte dans les 24h."

❌ "Votre message a été envoyé avec succès."
❌ "Nous avons bien reçu votre demande. Notre équipe vous contactera."
❌ "Merci pour votre confiance."
```

## Test rapide de copywriting

Avant de valider un texte, se poser ces 3 questions :

1. **Peut-on remplacer "L'Écrin" par n'importe quel autre traiteur et que ça reste vrai ?**
   → Si oui : le texte est trop générique. Le reformuler avec du concret (producteur, lieu, produit).

2. **Ce texte montre-t-il ou affirme-t-il ?**
   → "Nous utilisons des produits artisanaux" = affirmation vague.
   → "Nos viennoiseries viennent de la Boulangerie Morin, Provins" = preuve.

3. **Est-ce qu'un office manager pressé comprend en 3 secondes ce qu'on lui propose ?**
   → Si non : simplifier. Couper. Reformuler.
